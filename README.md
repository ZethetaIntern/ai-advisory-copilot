A production-grade, fiduciary advisory co-pilot engineered for SEBI-registered Investment Advisers (RIAs). The system performs deterministic client risk profiling, builds inflation-adjusted goal plans with linear glide paths, answers mutual fund research questions with verbatim page-level citations, and enforces multi-layer compliance guardrails.

**Core Fiduciary Rule:** *The LLM explains and drafts text; Python computes every single number. The adviser stays in control: nothing reaches a client without explicit adviser approval.*

## 🔒 Hard Constraints & Fiduciary Guarantees

1. **Deterministic Computation**: Every rupee, percentage, SIP amount, and CAGR is generated by closed-form Python formulas—never by an LLM prompt.
2. **Zero Return Guarantees**: Prohibited words (*"guarantee"*, *"assured return"*, *"double money"*) are scanned and blocked at both input and output layers.
3. **Strict Verifier (Anti-Hallucination)**: RAG answers must cite exact document and page coordinates `[Doc, p.X]`. Every claimed number is verified against the cited text. Any unverified claim triggers an honest refusal: *"Not found in the provided sources."*
4. **Code-Enforced Approval Gate**: Governed by a formal state machine (`DRAFT` $\to$ `PENDING_REVIEW` $\to$ `APPROVED`). Calling `export_pdf()` when status $\ne$ `APPROVED` raises a Python `PermissionError`.
5. **Direct Plans Only**: Strictly screens Direct + Growth mutual fund plans (zero distributor commissions), in full alignment with SEBI RIA regulations.
6. **Open Data**: Integrates AMFI daily `NAVAll.txt`, mfapi.in historical NAV time series, and official AMC Factsheets/SIDs.

## ⚡ Quick Start

```bash
# 1. Clone repository
git clone <repo-url>
cd Z

# 2. Setup environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# 3. Install pinned dependencies
pip install -r requirements.txt

# 4. Download and cache open data
python scripts/download_data.py

# 5. Run full test suite (73 tests)
pytest tests/ -v

# 6. Launch Streamlit Adviser Dashboard
streamlit run app/dashboard.py
```
